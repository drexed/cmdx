# References

Most of this site walks you through ideas in plain language. This page is the **shortcut shelf** — links to lookup material, exports, and tooling that lives outside those guides.

Grab what you need:

| Link | When to open it |
|------|-----------------|
| [API documentation](https://drexed.github.io/cmdx/api/index.html) | You know the class or method name and want the official Ruby API write-up (generated from YARD in the repo). |
| [llms.txt](https://drexed.github.io/cmdx/llms.txt) | You are pointing an AI assistant at CMDx and want a **small** map of the doc tree — titles and URLs, not the whole novel. |
| [llms-full.txt](https://drexed.github.io/cmdx/llms-full.txt) | Same idea as `llms.txt`, but with the **full** documentation text in one file — handy when the tool can ingest a big paste or fetch one URL. |
| [AI skills](https://github.com/drexed/cmdx/blob/main/skills) | You use Cursor or Claude with skills and want ready-made helpers for writing, testing, and debugging CMDx code in this repository. |

**Quick pick:** humans debugging in the IDE usually start with the API docs; bots and automation usually start with `llms.txt` or `llms-full.txt`.
