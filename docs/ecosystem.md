# Ecosystem

CMDx on its own is the runtime, the DSL, and the docs you are reading now. When you want **extra** tooling around that core, these satellite gems pick up the slack — install only what you need.

| Gem | What it is for |
|-----|----------------|
| [cmdx-i18n](https://github.com/drexed/cmdx-i18n) | More internationalization helpers on top of CMDx’s built-in locales — handy when error copy and validations need to live in many languages. |
| [cmdx-rspec](https://github.com/drexed/cmdx-rspec) | RSpec matchers and helpers tuned for tasks, results, and workflows so your specs read like the framework does. |

They follow the same release cadence and conventions as core CMDx. If you are browsing an older gem version, check that repo’s README for compatibility with your `cmdx` version.
