Overview

Declared via Task.idempotent_by. After inputs resolve, claims a shared store slot and runs the retry_on loop inside that claim so duplicate invocations with the same logical key short-circuit before work repeats.

Store keys are namespace:TaskName:segment (see StoreKey#compose). Values move processing → completed after the wrapped block returns (including output verification when invoked from Runtime); the key is deleted on StandardError or non-success signals (skip! / fail!) so retries can reclaim.

def build(new_key, new_options)
  return self if new_key.nil? && new_options.empty?

  merged_key     = new_key.nil? ? @key : new_key
  merged_options = @options.merge(new_options)

  self.class.new(merged_key, merged_options)
end

def process(task)
  return yield unless enabled?
  return yield unless Util.satisfied?(condition_if, condition_unless, task)

  segment = StoreKey.segment(task, key)
  return yield if segment.nil?

  store_key = StoreKey.compose(namespace, task.class.name, segment)

  if Stores.set(store_key, PROCESSING, nx: true, ttl:)
    succeeded = false

    begin
      yield
      succeeded = true
    rescue StandardError
      Stores.del(store_key)
      raise
    ensure
      Stores.del(store_key) unless succeeded
    end

    mark_completed!(store_key)
  else
    duplicate!(task, store_key)
  end
end
