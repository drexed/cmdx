Overview

Declared via Task.lock_with. After inputs resolve, acquires a store lease (SET with nx: true) and runs idempotency (when declared), the full retry_on loop, and output verification inside that lease.

Store keys are namespace:TaskName:segment (see StoreKey#compose). The stored value is the holding task's tid. Release uses a conditional delete so a late releaser cannot drop a newer holder's lease after TTL expiry.

After a successful acquire, the lease is released in ensure for any exit from the wrapped block (success, skip! / fail!, or uncaught error). The lease is not released between in-process retry_on attempts.

def build(new_key, new_options)
  return self if new_key.nil? && new_options.empty?

  merged_key     = new_key.nil? ? @key : new_key
  merged_options = @options.merge(new_options)

  self.class.new(merged_key, merged_options)
end

def process(task)
  return yield unless enabled?
  return yield unless Util.satisfied?(condition_if, condition_unless, task)

  segment = StoreKey.segment(task, key)
  return yield if segment.nil?

  store_key = StoreKey.compose(namespace, task.class.name, segment)
  token = task.tid

  if acquire_lock(store_key, token)
    Telemetry.emit_for(task, :lock_acquired, lock_key: store_key)

    begin
      yield
    ensure
      release_lock(store_key, token)
    end
  else
    busy!(task, store_key)
  end
end
