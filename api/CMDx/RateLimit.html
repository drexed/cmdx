Overview

Declared via Task.rate_limit. After inputs resolve, consults a shared limiter once per execution (retries do not consume additional quota) and short-circuits before the circuit breaker when the bucket is full.

Store keys come from StoreKey#task_key with class_scoped: true — either namespace:TaskName for {StoreKey::CLASS_KEY} (:class) or namespace:TaskName:segment when a resolver yields a segment.

def build(new_key, new_options)
  return self if new_key.nil? && new_options.empty?

  merged_key =
    if new_key.nil?
      enabled? || new_options.empty? ? @key : StoreKey::CLASS_KEY
    else
      new_key
    end
  merged_options = @options.merge(new_options)

  self.class.new(merged_key, merged_options)
end

def process(task)
  return yield unless enabled?
  return yield unless Util.satisfied?(condition_if, condition_unless, task)

  store_key = StoreKey.task_key(task, namespace:, resolver: key, class_scoped: true)
  return yield if store_key.nil?

  quota = Quota.new(
    task:,
    store_key:,
    max: Integer(max),
    per: Integer(per),
    cost:,
    limiter:,
    options: @options
  )

  admission = invoke_limiter(task, quota)
  if admission.admitted?
    admitted!(task, store_key, admission, quota)
    yield
  else
    exceeded!(task, store_key, admission, quota)
  end
end
