Overview

Shared store key helpers for store-backed task features (Idempotency, CircuitBreaker, Lock, RateLimit, and others).

#compose joins colon-separated segments, each coerced with CMDx::Stores#key!. #segment resolves a per-invocation suffix from a declaration (symbol, proc, callable, or literal).

Resolver for one breaker or limiter per task class (see CircuitBreaker, RateLimit). Not used for segment-required features (Idempotency, Lock).

def segment(task, resolver, skip: nil)
  return if skip && resolver == skip

  raw =
    case resolver
    when Symbol
      task.context[resolver]
    when Proc
      task.instance_exec(task, &resolver)
    else
      return resolver.call(task) if resolver.respond_to?(:call)

      resolver
    end

  str = raw&.to_s
  str if str && !str.empty?
end

def task_key(task, namespace:, resolver:, class_scoped: false)
  skip = class_scoped ? CLASS_KEY : nil
  segment_value = segment(task, resolver, skip:)

  if segment_value.nil?
    return compose(namespace, task.class.name) if class_scoped && resolver == CLASS_KEY

    return nil
  end

  compose(namespace, task.class.name, segment_value)
end
